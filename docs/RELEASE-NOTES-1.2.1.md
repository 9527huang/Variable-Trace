# Variable-Trace 1.2.1

基于 MCUViewer 1.1.0（GPLv3，作者 Piotr Wasilewski）修改并更名。上游此后闭源，
本项目在 1.1.0 那份快照上独立演进。

解压即用：`Variable-Trace.exe` 与随包的 DLL 必须放在同一目录，手册是同目录的 HTML 文件。

> 1.2.0 的发布包是在界面改造之前打的，里面没有下面这些内容。已经用过 1.2.0 的，
> 直接换这一版即可，工程文件与全局设置兼容（`rtos.view` 里旧的 `showOnlyBlocked`
> 会被读成"只看阻塞"模式，不必手工改）。

## 这一版（1.2.1）的重点

### 时间线：从"一堆竖线"改成"能看出趋势的色带"

- 相邻采样聚合成**状态区间**并画成连续色带（绿运行 / 蓝就绪 / 橙阻塞 / 灰挂起），
  一眼能答"谁在跑、谁在等"。
- **空白有了语义**：紫色是"这一轮没读到这个任务"，历史范围之外才没有颜色。图例与说明行
  写明"未采样不等于没在跑"。
- 说明行写清**请求窗口与实际窗口**（`showing 10.80 s of 10 s asked, 19 rounds`），
  不再让读者从坐标轴猜。

### 任务表：先给结论，再给数据

- 摘要直接回答三个问题：**最忙的是谁**（`busiest inv_mid 37.6%`）、**谁等得最久**
  （`longest wait stuck 35 s`）、**有几个没读到**。
- 默认**按问题排序**：栈告警 > 阻塞且有等待对象 > 优先级继承 > 任务占比 > 名称。
  点任一列头改成按列排，表下一行说明当前是哪种，并给一个"回到问题排序"。
- 选中任务详情加 `Last ran`（多久以前跑过），以及 `Problems`（这个任务被哪几条发现抓到）。

### 四个问题模式

任务表上方一排互斥按钮，先决定"看哪些"，下面的搜索与阈值在这个范围里再收窄：

| 按钮 | 留下什么 |
|---|---|
| `all tasks` | 这一轮读到的每个任务 |
| `problems only` | 栈剩余到或低于阈值的、优先级被继承抬高的、以及"发现"点到名的任务（死锁环、无超时等待、就绪却没被切入） |
| `blocked only` | 在等某个东西的任务，不管这段等待有没有超时 |
| `high share only` | 任务时间占比到或高于下限（默认 10%，可当场改） |

**筛选同时管泳道**：表格剩三行，图上就剩三条。说明行会写"13 个任务里有 4 个有泳道"，
因为少掉的泳道很容易被读成"这些任务没在跑"。筛空时那一行直接说原因。

`problems only` 故意**不包含**"每个阻塞在对象上的任务"——内核健康时那是大多数任务，
一个回答"全都有问题"的筛选没人会用第二次。鼠标停在按钮上有这一段原话。

### 界面不再自己上下跳

Findings 区块、任务表、右栏三块（同步对象 / 钉住时刻 / 选中任务）原本都按内容算高度，
数据一变界面就挪一次。现在高度固定，内容滚动或留白。

### 中文界面

补上 **22 条**一直显示英文的文案（记录器、采集设置、截图、变量表、任务视图各几处）。
这些都是手写的 `I18n::tr`，抽取器看不见，所以之前一直没被发现。

记录器里三条用字符串拼出来的提示（"已写入 …"）改成一条格式串——原来的拼法只有前半句
会被翻译，括号里的样本数永远显示英文。

## 已知限制

| 限制 | 说明 |
|---|---|
| 个别探针会在读控制块时卡住 | 到「采集设置」里关掉 `Task view: read control blocks`。任务表会只剩状态和地址，变量视图不受影响 |
| SWO 与任务视图读数不能共存（J-Link） | 一颗 J-Link 同时只服务一条连接 |
| RTT 通路当前不可用 | 目标侧已就绪，J-Link 的 DLL 能找到控制块但读不出数据。默认的内存环通路不受影响 |
| 任务视图只能看到被调度过的东西 | 内核不维护"切换次数"，所以没有这一列 |
| 右键交互（表头列菜单、复制关系链）未做脚本化验证 | 本机自动化无法向内注入右键，功能本身可用，需要人工点一次 |

```
JLink_x64.dll               SEGGER J-Link 运行库
glfw3.dll                   窗口与输入
libusb-1.0.dll              USB（部分探针）
libdwarf-2.dll              ELF/DWARF 读取
libzstd.dll, zlib1.dll      libdwarf-2.dll 的依赖
Variable-Trace-User-Guide.html   上手指南
RELEASE-NOTES-1.2.1.md      本文件
```
